# Job Search

A job search front-end application built with Vue 3 and Vite.

## About The Project

This project is a Vue 3 single-page application scaffolded with Vite, with unit tests (Vitest), ESLint and Prettier configured.

## Built With

- Vue 3
- Vite
- Vitest

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build and test

```bash
npm run build
npm run test:unit
```
